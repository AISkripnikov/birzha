# Birzha — сигналы по свечам для Bybit

Веб-страница, которая следит за криптовалютами на Bybit (спот), анализирует свечи и индикаторы
и подсказывает: входить или нет, на какую сумму, где ставить стоп-лосс и тейк-профит.

## Как запустить

Нужен Python 3. На Windows откройте двойным кликом `start.bat` — браузер откроет http://localhost:8000.
Окно с сервером не закрывайте, пока пользуетесь страницей.

Или из командной строки в папке проекта:

```bash
python server.py
```

`server.py` работает только у вас на компьютере: раздаёт страницу и пересылает запросы публичных рыночных
данных к Bybit (без него браузер их блокирует). Ключи API не нужны, торговать сервер не может —
он пропускает только `/v5/market/*`.

## Что на странице

- **Лента монет** — 16 популярных монет с ценой и изменением за сутки, клик открывает график.
- **График** свечей с объёмами, EMA 20/50/200, полосами Боллинджера, RSI и метками прошлых сигналов BUY/SELL.
- **Сигнал сейчас** — шкала от «продавать» до «покупать» и расшифровка оценки:
  тренд (EMA), RSI, MACD, Боллинджер, свечные паттерны (поглощение, молот, падающая звезда, доджи) с учётом объёма.
- **Сколько ставить** — размер позиции по риску: при срабатывании стопа теряется не больше заданного %
  депозита. Стоп = 1,5×ATR, тейк = 2× расстояния до стопа. Без плеча.
- **Проверка на истории** — как сработали бы сильные сигналы на загруженных свечах.
- **Сканер** — все монеты, отсортированные по силе сигнала, с суммой входа.

Файлы: `index.html`, `style.css`, `indicators.js` (вся математика), `app.js` (данные Bybit, графики, интерфейс),
`server.py` и `start.bat` (локальный запуск).

## ⚠️ Важно

Это не финансовая рекомендация. Технические индикаторы часто ошибаются, стратегия рассчитана только на покупки
(спот). Смотрите на блок «Проверка на истории» — он честно показывает, работали ли сигналы на этой монете.
