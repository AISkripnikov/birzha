# Биржевой помощник (крипта, Bybit / Binance)

Веб-страница, которая следит за криптовалютами на Bybit или Binance (переключатель вверху), анализирует свечи и индикаторы
и подсказывает: входить или нет, на какую сумму, где ставить стоп-лосс и тейк-профит.

## Как запустить

**Bybit (рекомендуется):** нужен установленный Python 3. На Windows просто откройте двойным кликом `start.bat`.
Или в папке проекта выполните

```bash
python server.py
```

Откроется http://localhost:8000. Сервер работает только у вас на компьютере: раздаёт страницу и пересылает
запросы публичных рыночных данных к Bybit. Без него браузер может заблокировать такие запросы (CORS).
Ключи API не нужны, торговать сервер не умеет: он пропускает только `/v5/market/*`.

**Binance:** можно просто открыть `index.html` двойным кликом и выбрать «Binance» в списке бирж.

## Что внутри

- **График** свечей с EMA 20/50/200, полосами Боллинджера, RSI и метками прошлых сигналов BUY/SELL.
- **Сигнал сейчас** — оценка от −7 до +7 и расшифровка, из чего она сложилась:
  тренд (EMA), RSI, MACD, Боллинджер, свечные паттерны (поглощение, молот, падающая звезда, доджи) с учётом объёма.
- **Сколько ставить** — размер позиции по риску: при срабатывании стопа теряется не больше
  заданного % депозита (по умолчанию 1%). Стоп = 1.5×ATR, тейк = 2× расстояния до стопа. Без плеча.
- **Проверка на истории** — как сработали бы сильные сигналы на загруженных свечах.
- **Сканер** — 16 популярных монет, отсортированных по силе сигнала. Клик по строке открывает монету.

Файлы: `index.html` (разметка), `style.css`, `indicators.js` (вся математика), `app.js` (данные бирж, графики, интерфейс), `server.py` (локальный сервер для Bybit).

## ⚠️ Важно

Это не финансовая рекомендация. Технические индикаторы часто ошибаются, а стратегия рассчитана только на покупки
(спот). Смотрите на блок «Проверка на истории» — он честно показывает, работали ли сигналы на этой монете.
