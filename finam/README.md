# Боты для Финама

В папке два бота:
- **Фьючерсы, внутри дня (короткие сделки)** — `fut_*.py`, описан ниже.
- **Акции, сделки на недели и месяцы** — `bot.py`, `backtest.py`, описан ниже в разделе «Стратегия для акций».

---

# Фьючерсы: внутридневной пробой по тренду

Торгует **вечные фьючерсы** Мосбиржи: USDRUBF (доллар), CNYRUBF (юань), GLDRUBF (золото),
IMOEXF (индекс), SBERF, GAZPF. У них нет экспирации, поэтому не нужно переходить из
контракта в контракт. Работает в лонг и в шорт, **все позиции закрывает до конца основной сессии**:
ночью вы без позиций.

| Шаг | Правило |
|---|---|
| Свечи | 30 минут (можно 10 или 60), основная сессия 10:00–18:50 МСК |
| Направление | Лонг — только если цена выше EMA50 и EMA20 выше EMA50. Шорт — наоборот |
| Вход | Свеча закрылась выше максимума (ниже минимума) 12 прошлых свечей |
| Стоп | 2×ATR от входа. Дальше тянется за ценой и ставится **стоп-заявкой на бирже** |
| Ограничения | До 2 сделок в день на инструмент, новых входов после 17:30 нет, в 18:40 всё закрывается |
| Риск | Стоп = 0,5 % капитала на сделку. Всё ГО вместе — не больше 50 % капитала. При −2 % за день торговля стоп до завтра |

Все настройки лежат в `fut_config.py`.

## Сайт с живыми свечами и сигналами

```bash
python fut_web.py
```

Windows: дважды щёлкните `fut_web.bat`. Откроется http://localhost:8010. Окно с сервером не закрывайте.

На сайте:
- лента фьючерсов с ценой и изменением за день;
- свечной график (10 мин / 30 мин / 1 ч) с EMA, уровнями пробоя и входами/выходами стратегии;
- блок «Сигнал сейчас»: тренд, до какого уровня осталось дойти до входа, открыто ли окно входа;
- расчёт: сколько контрактов брать под ваш капитал, риск в рублях, ГО и стопы;
- результаты стратегии за последние 30 дней и список сделок.

Данные обновляются каждые 10 секунд. Без токена они берутся с Мосбиржи с задержкой ~15 минут.
Задайте `FINAM_TOKEN`, и данные пойдут от Финама в реальном времени. Сайт только показывает
данные и сигналы, заявок он не отправляет.

## 1. Проверка на истории (токен не нужен)

```bash
python fut_backtest.py --split 2025-06-01
```

Windows: `fut_backtest.bat`. Скрипт скачает 10-минутные свечи с Мосбиржи и покажет:
- доходность и просадку;
- число сделок в день;
- результаты по лонгам и шортам, по инструментам и по месяцам.

Смотрите строку **«После 2025-06-01 (экзамен)»**. Добавьте `--trades`, чтобы увидеть каждую сделку,
или `--tf 10`, чтобы попробовать 10-минутные свечи.

> Внутри дня комиссии съедают много. На случайных ценах без трендов эта же стратегия
> теряет десятки процентов в год (это видно в тестах). Если на истории profit factor ниже ~1,2, торговать нельзя.

## 2. Бумажная торговля

```bash
python fut_bot.py --capital 200000
```

Запустите до 10:00 МСК и не закрывайте окно. После закрытия каждой свечи бот пишет сигналы,
входы, перенос стопа и выходы, а около 19:00 подводит итог дня и сам останавливается.
С токеном Финама свечи приходят в реальном времени. Без токена они берутся с Мосбиржи
с задержкой ~15 минут: так можно только посмотреть, как бот работает.

## 3. Реальная торговля

1. Сдайте тест на фьючерсы в приложении Финама и пополните счёт срочного рынка.
2. Задайте переменные `FINAM_TOKEN` и `FINAM_ACCOUNT_ID`.
3. Проверьте символы в `fut_config.py` командой `python fut_bot.py --find USDRUBF`.
   Если в ответе не `USDRUBF@RTSX`, впишите правильный символ в конфиг.
4. Сверьте ₽ за пункт и ГО со спецификацией контракта на moex.com.
5. Запустите `python fut_bot.py --live --only USDRUBF`. Начинайте с одного инструмента и минимального капитала.

Перед стартом в режиме `--live` на счёте не должно быть позиций по этим фьючерсам.
Если бот выключится посреди дня, стоп-заявки на бирже останутся, но **закрыть позицию в 18:40 будет некому**.
Тогда закройте её вручную в терминале.

# Стратегия для акций: тренд + пробой + фильтр рынка

Python-бот для акций Мосбиржи через [Finam Trade API](https://tradeapi.finam.ru/docs/).
Нужен только Python 3.9+, сторонние библиотеки не нужны.

## Как работает стратегия

Торгует только в лонг на дневных свечах, по 16 самым ликвидным акциям (список в `config.py`).

| Шаг | Правило |
|---|---|
| Фильтр бумаги | Цена выше EMA200, EMA50 выше EMA200: бумага в долгосрочном аптренде |
| Фильтр рынка | Новые покупки только если ≥ 50 % бумаг выше своей EMA200. В обвалы (2022) деньги остаются в кэше |
| Вход | Закрытие выше максимума за 40 дней. Покупка на следующий день |
| Выбор | Если сигналов больше, чем свободных мест, берутся самые сильные за полгода |
| Выход | Трейлинг-стоп: максимум с момента входа − 3×ATR(20). Стоп только поднимается |
| Размер | При срабатывании стопа теряется ~1 % капитала. Не больше 20 % на бумагу и 6 позиций |

Это классическая трендовая система. Обычно 35–45 % сделок убыточны, но убытки
маленькие, а прибыльные сделки крупные. Она зарабатывает на сильных трендах и платит
мелкими убытками в боковике. Гарантий прибыли нет.

## 1. Проверить на истории (токен не нужен)

```bash
cd finam
python backtest.py --split 2022-01-01
```

История загружается бесплатно с Мосбиржи (iss.moex.com) и кешируется в `finam/cache/`.
Скрипт показывает доходность, просадку, коэффициент Шарпа, долю прибыльных сделок и сравнение
с «купил и держи». Главная строка — **«После 2022-01-01 (экзамен)»**. Если на этом
отрезке стратегия не лучше «купил и держи» с учётом просадки, ей нельзя доверять деньги.

Учтите: дивиденды в истории не учитываются (это минус и стратегии, и «купил и держи»),
сплиты поправлены автоматически.

## 2. Бумажная торговля (без риска, минимум 1–3 месяца)

```bash
python bot.py --capital 300000
```

Запускайте раз в день после 19:00 МСК. Бот напишет, что купить, что держать, что продать и где стоп,
и будет вести виртуальный счёт в `paper_state.json`.
Уведомления в Telegram: задайте `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`.

## 3. Реальная торговля через Финам

1. Получите токен в личном кабинете Финама: раздел Trade API → «Токены».
2. Задайте переменные окружения (Windows: `set FINAM_TOKEN=...`):
   - `FINAM_TOKEN` — токен;
   - `FINAM_ACCOUNT_ID` — номер счёта.
3. `python bot.py --live`. Бот спросит подтверждение. Для планировщика добавьте `--yes`.

В режиме `--live` бот покупает по рынку и сразу ставит на бирже **стоп-заявку на продажу**
(действует до отмены). Каждый день он подтягивает её вверх. Если компьютер выключен,
стоп всё равно защищает позицию.

Начинайте с суммы, которую не жалко потерять. Первые запуски `--live` смотрите глазами
и сверяйте заявки в терминале Финама.

## Файлы

- `config.py` — бумаги, параметры, риск, комиссии.
- `strategy.py` — индикаторы и правила.
- `engine.py` — симулятор портфеля и сигналы.
- `backtest.py` — проверка на истории.
- `bot.py` — ежедневные сигналы и торговля.
- `finam_api.py` — клиент Finam Trade API.
- `data.py` — история с Мосбиржи.
- `test_strategy.py`, `test_futures.py` — тесты: `python -m unittest test_strategy test_futures`.
- `fut_config.py`, `fut_strategy.py`, `fut_backtest.py`, `fut_bot.py` — фьючерсы внутри дня.
- `fut_web.py` и папка `web/` — сайт с живыми свечами и сигналами.

## ⚠️ Честно о рисках

- «Топовой» стратегии с гарантированным заработком не существует. Кто её продаёт, тот зарабатывает на продаже.
- Не подгоняйте параметры под историю до красивых цифр: на будущем это почти всегда ломается.
- Трендовая система может проигрывать 1–2 года подряд в боковом рынке. Это нормально для неё.
- Без плеча, без шортов. Это не финансовая рекомендация.
